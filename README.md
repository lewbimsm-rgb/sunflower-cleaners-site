# Sunflower Cleaners — website

One-page static site for Sunflower Cleaners, 50 N Valle Verde Dr Ste 120, Henderson NV 89074.
No build step: `index.html` + `images/` is the whole site.

**Hosting:** Vercel, linked to this repo. Every push to `main` goes live in about a minute.

**To change something:** edit `index.html`, commit, push. Done.

**If the address ever changes:** `python ../set_domain.py https://new-domain.com` (lives one folder up in Lewis's workspace), then commit + push.

Source photos and the full-size originals live outside this repo in Lewis's workspace.
